# Code Style

This project follows the Airbnb JavaScript Style Guide.

Source: https://github.com/airbnb/javascript

## Key Rules

1. Use `const` and `let`; never use `var`.
2. Use single quotes for strings.
3. Component file names use PascalCase (e.g. `Calculator.vue`).
4. Variable and function names use lowerCamelCase (e.g. `loadHistory`).
5. Use 2 spaces for indentation.
6. Always end statements with a semicolon.
7. Each Vue component is divided into `<template>`, `<script setup>`, and `<style scoped>` sections.
8. Declare component state with `ref`.
9. Name API functions after the action they perform (e.g. `calculate`, `getHistory`).
